**Executable content** is anything palm writes that makes a harness, or a program it starts, run code.
Before palm writes any of it, you see every command and script, and you answer yes. The default answer is no.

```sh
palm install trailofbits/skills plugin:gh-cli --dry-run
```

`--dry-run` prints the same review a terminal prompt shows and writes nothing.

## What counts

| Executable | Gated | Why |
| --- | --- | --- |
| hook commands, per event and matcher | yes | the harness runs them on every matching event |
| stdio MCP servers: command, arguments, working directory, environment keys | yes | the harness starts the program |
| the scripts those reach, copied to `.palm/assets/` | yes, as part of the unit | a changed script byte changes what runs |
| prompt hooks (`type: prompt`) | no | text sent to the model; listed, never called a command |
| remote MCP servers (a URL) | no | nothing runs on your machine; the review says which is which |
| skills that cite scripts, such as `scripts/find-polluter.sh` | no | the harness asks before the model runs a shell command; `palm describe` lists them |

palm itself never runs what it installs. The only programs palm starts are git and your pager.

## The review

On a terminal, palm prints one block per program and asks once.
This is the prompt as palm prints it for a plugin hook and a stdio MCP server.

```text
This install adds 2 programs that will run on your machine.

  1. hook gh-cli  from trailofbits/skills  (commit 82fe822, v2.1.0, 2026-07-14)
     SessionStart          bash "$CLAUDE_PROJECT_DIR"/.palm/assets/trailofbits__skills/gh-cli/hooks/persist-session-id.sh
     PreToolUse  Bash      bash "$CLAUDE_PROJECT_DIR"/.palm/assets/trailofbits__skills/gh-cli/hooks/intercept-github-curl.sh
     targets: claude (.claude/settings.json), cursor (.cursor/hooks.json)
     scripts: 8 files, 21 KB  ->  .palm/assets/trailofbits__skills/gh-cli/  (committed with your repo)
       hooks/persist-session-id.sh     755   612 B   sha256:1b9e04c2
       hooks/intercept-github-curl.sh  755   1.1 KB  sha256:77d0a9f1
       ... 6 more  (v shows every script)
  2. mcp team-helper  from acme-kit  (commit 61ec102, v1.1.1)
     stdio  node ".palm/assets/acme-kit/team-helper/server.js"   env: none
     targets: claude (.mcp.json), cursor (.cursor/mcp.json)

  Also 1 prompt hook (text sent to the model; no program runs): fp-check Stop.

palm never runs these itself. If you say yes, their hashes go into palm.lock.yaml,
so teammates and CI install them without being asked; any change asks again.

Allow these 2 programs to run?  [y/N/v=view scripts]
```

Each block names the source, the commit, the tag and its date.
It shows every command as the harness will run it, the file it lands in per target, and the scripts with mode, size and a short hash.

| Key | Does |
| --- | --- |
| `y` | allows every program in the list |
| `n` or Enter | declines; the default |
| `v` | pages every script body from the pinned commit |
| `d` | during `palm update`, pages a unified diff against the version you trusted |

## One hash per program

palm hashes each program as one unit.
The hash covers the commands before per-harness rendering, with their events and matchers.
It also covers the environment keys, the working directory, and a tree hash of every script the unit reaches, mode bits included.

| Asks again | Does not ask again |
| --- | --- |
| a new hook or stdio server | the same hash at a newer commit |
| any changed command, script byte, mode bit, environment key or working directory | a target you add |
| a trust entry removed from the lock | a newer palm version |

## Consent lives in the lock

A yes is recorded once, in `palm.lock.yaml`, as a `trust:` hash on the entry.
Every later install replays it silently while the hash matches: yours, a teammate's and CI's.

The lock diff is the team's consent record.
A reviewer sees the readable `command:` lines and one hash line beside them, and approves both in the same pull request.

## Without a terminal

palm never prompts without a terminal, and `--yes` never consents.
A program without a trusted hash stops the command with `E_UNTRUSTED_EXEC`, and the error prints the exact line that consents.

```text
x 2 programs need your consent and there is no terminal
  review:  palm install --dry-run --review
  then:    palm install --allow-exec hook:gh-cli@trailofbits/skills=sha256:a7cc7911,mcp:team-helper@acme-kit=sha256:75aafd9b
```

`--allow-exec` takes `<kind>:<name>@<source>=<hash>`, comma-separated for several.
The hash may be a prefix of at least eight hex characters.
It pins the exact program you reviewed, so a changed script fails again instead of slipping through.
`--allow-exec all` works only on a terminal.

## Declining

Declining a plugin's hook installs the rest of the plugin and records the hook as declined.
Later bare installs stay quiet about it.
`palm install <source> hook:<name>` asks again.
