palm is a package manager for the files that configure AI coding agents.
You name a skill, a subagent or an MCP server.
palm writes it where each of your tools reads it.

```sh
npm install -g @paliontech/palm
palm install origin mattpocock/skills
palm install skill tdd
```

## One item, six formats

Coding agents read the same kinds of files: skills, subagents, instructions, commands, hooks and MCP servers.
Each harness expects them in its own place and format.
A subagent is a Markdown file in `.claude/agents` for Claude Code.
Codex wants a TOML file in `.codex/agents`, and Copilot wants an `.agent.md` file in `.github/agents`.
An MCP server goes into `.mcp.json`, `.codex/config.toml`, `.vscode/mcp.json`, `.cursor/mcp.json`, `.gemini/settings.json` or `opencode.json`.
Each of those files spells an environment variable differently.

Copying by hand means one edit per harness for every change, and nothing records what you copied.
palm reads a repository as its author published it and writes each item in each harness's format.
It records every file in `palm.lock.yaml`.
A teammate repeats the setup with one command, and an uninstall removes exactly what palm wrote.

## When palm helps

| Situation | What palm does |
| --- | --- |
| You use two or more harnesses on one repository | One install writes the item for each of them. |
| Your team shares skills, agents and MCP servers | `palm install` in a fresh clone installs what `palm.yaml` lists, from the commits in the lockfile. |
| CI must use the same setup as your laptop | `palm install --frozen` fails when the files, the manifest and the lockfile disagree. |
| An agent needs skills and an MCP server | Installing the agent installs them, and uninstalling it removes what nothing else uses. |
| You publish skills or plugins | Users install from your repository as it is, with no palm-specific manifest. |

This session installs one agent and one skill for all six harnesses.
The origins `pstack` and `mattpocock` were added before it.

- `palm.yaml` is the **manifest**. It lists what you asked for, and you commit it.
- `palm.lock.yaml` is the **lockfile**. It records every file palm wrote, with a content hash. Commit it too.
- The agent exists once per harness format.
- The skill exists twice, because Claude Code does not read `.agents/skills`.

## Commands

Every command has the form `palm <verb> <kind> [names]`, as in `palm install skill tdd`.
