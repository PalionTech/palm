In five minutes you install a skill from `mattpocock/skills` for Claude Code and Codex, prove the setup is consistent, and remove it again.
Every step is one command.

```sh
palm init --target claude,codex
palm install mattpocock/skills
palm install mattpocock/skills grill-me
palm check
```

## Before you start

- palm is installed. See [Installation](/palm/getting-started/install/).
- You are inside a git repository.

palm treats the nearest directory with a `palm.yaml`, or else the nearest `.git`, as the project root.
It refuses to treat your home directory as a project, so run these steps inside one.

## Steps

<Steps>
1. Choose the harnesses for this project.

   ```sh
   palm init --target claude,codex
   ```

   palm writes `targets: [claude, codex]` to `palm.yaml`.
   It adds `.palm/local/` and `palm.local.yaml` to `.gitignore`, the only palm paths you do not commit.
   Without `--target`, palm detects the harnesses from folders such as `.claude/` and `.cursor/`.

2. See what the repository offers.

   ```sh
   palm install mattpocock/skills
   ```

   With no names, palm fetches the repository, lists its skills, agents, rules, hooks and MCP servers, and writes nothing.
   The last lines are commands you can paste.

3. Install a skill.

   ```sh
   palm install mattpocock/skills grill-me
   ```

   palm declares `mattpocock/skills` in `palm.yaml` with a version range, writes the skill for both harnesses and pins the commit in `palm.lock.yaml`.

4. Check the result.

   ```sh
   palm check
   ```

   `palm check` recomputes every generated file from the lock and changes nothing. CI runs the same command.

5. Commit.

   ```sh
   git add palm.yaml palm.lock.yaml .gitignore .claude .agents
   git commit -m "Add the grill-me skill"
   ```
</Steps>

## What happened

This is a recorded session of steps 1 to 3.

<Capture name="a-quick-start" title="~/project" />

The session created these files.

<CaptureTree name="a-quick-start" />

- Claude Code reads the copy in `.claude/skills/grill-me/`.
- Codex reads the copy in `.agents/skills/grill-me/`. Copilot, Gemini CLI and OpenCode read that folder too.
- `palm.yaml` now declares `mattpocock/skills` with `ref: ^1.2`, the newest tag's minor range, and lists `grill-me` under it.
- `palm.lock.yaml` records the commit, one render hash per harness and the four file paths.

Start a new Claude Code or Codex session in the project, and the skill is available.
`palm describe grill-me` shows the source, the version and the files per harness.

## Remove it again

<Capture name="a-quick-start-remove" title="~/project" />

`palm remove` deleted the four files and every folder it emptied, and removed the entry from `palm.yaml` and the lock.
The source had nothing left, so palm removed it from `palm.yaml` too.
Only these two files changed.
