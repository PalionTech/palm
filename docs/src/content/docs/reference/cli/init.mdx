`palm init` starts a project. It writes `palm.yaml` with `targets:`, and adds palm's two ignore lines to `.gitignore`.

```sh
palm init [--target <ids>] [--here]
```

| Command | What it does |
| --- | --- |
| `palm init` | Detect the harnesses from folders such as `.claude/` and `.cursor/`, and write them as `targets:`. |
| `palm init --target claude,codex` | Write exactly these targets. |
| `palm init --target claude,codex,copilot,cursor,gemini,opencode` | All six. |
| `palm init --here` | Start a separate project in a folder that sits inside another project. |

## Options

{/* cli-reference:options init */}

| Option | Meaning |
| --- | --- |
| `--target <ids>` | comma-separated: claude, codex, copilot, cursor, gemini, opencode |
| `--here` | start a separate project in this directory |

The [global options](/palm/reference/cli/#global-options) also apply.

{/* /cli-reference */}

`--target` is singular here because it sets the project's whole list.
On `palm install`, `--targets` narrows one entry.

## Behavior

palm writes `targets:` to `palm.yaml` in the current folder and prints the path it wrote.
It adds `.palm/local/` and `palm.local.yaml` to `.gitignore`, creating the file when there is none.
Those are the only palm paths you do not commit.

Running `palm init` again with another `--target` rewrites `targets:`.
The next bare `palm install` writes files for an added target and removes the files of a dropped one.

`palm init` never writes outside the current folder.
Without `--target` and with no harness folder to detect, it stops with `E_TARGET` and names `palm init --target`.

## Inside another project

A folder inside a project that already has a `palm.yaml` above it, in the same repository, belongs to that project.
`palm init` there refuses and names both ways forward.

<Capture name="c-init-nested" title="~/project" />

`--here` makes the folder a project of its own, with its own `palm.yaml`, lock and generated files.
For one root setup with per-package placement, see [Monorepos](/palm/guides/monorepos/).

## Reads and writes

| File | Writes |
| --- | --- |
| `palm.yaml` | `targets:` |
| `.gitignore` | `.palm/local/` and `palm.local.yaml`, once |

## Exit codes

| Code | When |
| --- | --- |
| `0` | `palm.yaml` was written or updated. |
| `1` | No target given and none detected. |
| `2` | An unknown target, or a folder inside another project without `--here`. |
