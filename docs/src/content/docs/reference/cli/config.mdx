`palm config` reads and changes the settings in `~/.palm/config.yaml`.

```sh
palm config get [key]
palm config set <key> <value>
```

| Command | Meaning |
| --- | --- |
| `palm config get` | Every key with its value, or `(unset)`. |
| `palm config get targets` | One value. |
| `palm config set targets claude,codex` | Default targets for `-g` and for projects without their own. |
| `palm config set targets ''` | Unset the default targets. |
| `palm config set secrets.project literal` | Write MCP secret values into project files by default. |
| `palm config set mcpRegistryUrl https://registry.example.com` | Use another MCP registry. |

## Subcommands

| Command | Meaning |

| `palm config set <key> <value>` | Set a config value (an empty value unsets it). |

## Keys

| Key | Value | Unset with |
| --- | --- | --- |
| `targets` | A comma list of `claude`, `codex`, `copilot`, `cursor`, `gemini`, `opencode` | `''` or `none` |
| `mcpRegistryUrl` | A URL; palm drops trailing slashes | `''` |
| `secrets.project` | `env-ref` or `literal` | `''` |
| `secrets.global` | `env-ref` or `literal` | `''` |

Origins are not keys: add them with `palm install origin` and remove them with `palm uninstall origin`.
[config.yaml](/palm/reference/config-yaml/) describes the whole file.

## Behavior

`palm config set` writes `~/.palm/config.yaml` with mode `0600` and keeps its comments and key order.
With `--dry-run`, it prints the change and writes nothing.
`palm config get` writes nothing.
Neither prompts.

With `--json`, `get` returns `{ "<key>": <value or null> }` for each key it prints.

## Exit codes

| Code | When |
| --- | --- |
| `0` | The value printed or changed. |
| `1` | `config.yaml` cannot be read or parsed. |
| `2` | An unknown key, an invalid value, or no subcommand. |
