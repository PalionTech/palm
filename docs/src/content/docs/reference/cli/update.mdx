`palm update` re-resolves each source's `ref:` against its remote, prints a plan, asks, and installs what changed.

```sh
palm update [sources...] [--to <ref>] [--dry-run] [--strict] [--review]
```

Alias: `palm up`.

| Command | What it does |
| --- | --- |
| `palm update` | Plan and apply updates for every git source in `palm.yaml`. |
| `palm update mattpocock/skills` | Only this source. |
| `palm update --dry-run` | Print the plan and write nothing. This is the outdated report. |
| `palm update --dry-run --strict` | The same, and exit 1 when a source is behind its ref. |
| `palm update acme-kit --to ^2` | Move the ref in `palm.yaml` to a new range, then update. |
| `palm update --review` | Print script diffs of changed programs before the question. |
| `palm update --yes` | Apply without the plan question. Programs still need consent. |

## Options

{/* cli-reference:options update */}

| Argument | Meaning |
| --- | --- |
| `sources` | sources to update (default: all) |

| Option | Meaning |
| --- | --- |
| `--to <ref>` | move the ref in palm.yaml (a tag, branch, sha or range such as ^2) |
| `--review` | print changed scripts and entities as diffs before asking |
| `--strict` | with --dry-run: exit 1 when a source is behind its ref |

The [global options](/palm/reference/cli/#global-options) also apply.

{/* /cli-reference */}

## The plan

palm first plans without writing anything in the scope.
For each selected source it resolves the ref against the remote, fetches the new commit into the cache, indexes it and compares every entry.

```text
Update plan (project scope)
mattpocock/skills   ^1.2   v1.2.0 (3f2a1c9) → v1.2.3 (8be01d4)
~ updated    skill   tdd
+ added      skill   review (plugin:kit)          acme-kit
= unchanged  agent   reviewer                     acme-kit
! hook team-skills: setup.sh changed (sha256:a7cc… → 3e01…); d shows the diff
! you changed these files since palm wrote them; palm overwrites them only with --force:
    .claude/skills/tdd/SKILL.md  (skill tdd)
```

| Line | Meaning |
| --- | --- |
| `<source>  <ref>  <old> → <new>` | the source, its ref, and the move from the locked tag and commit to the new ones |
| `~ updated` | the entity's content changed |
| `+ added`, `- removed` | a plugin member the new version declares or dropped |
| `= unchanged` | same content; palm re-pins it to the new commit silently |
| `x failed` | the source is unreachable, or no longer has the entity |
| `⊘ skipped` | an in-repo source; `palm update` never touches those, a bare `palm install` does |
| `! hook ...` | a new or changed program, with its old and new hash |
| `! you changed these files` | generated files you edited; palm keeps them unless you pass `--force` |

Then palm asks `Apply N changes? [y/N]`. The default is no, and no changes nothing.
Without a terminal, `--yes` answers it. Without either, palm stops with `E_NON_INTERACTIVE` and names the command with `--yes`.

## Programs are never covered by `--yes`

A changed or new hook or stdio server goes through [consent](/palm/concepts/consent/) on its own, after the plan.
On a terminal, `d` pages a unified diff of each changed script against the version you trusted, and `v` pages the full scripts.
`--review` prints those diffs before the question, paged on a terminal.
Without a terminal, a changed program stops with `E_UNTRUSTED_EXEC` and the `--allow-exec` line to consent to its new hash.

## Applying

palm installs the changed entries as [palm install](/palm/reference/cli/install/#install-from-a-source) does, moves each source's commit and resolved tag in the lock, and writes the lock.
Entries whose content did not change are re-pinned to the new commit, so a second `--dry-run` reports nothing behind.
When git is present, palm prints `git diff --stat` of the scope, so you see what to commit.

`--to <ref>` moves the range itself. palm writes the new `ref:` to `palm.yaml` for the named sources, then plans against it.

## Reads and writes

| File | Reads | Writes |
| --- | --- | --- |
| `palm.yaml` | yes | only with `--to` |
| `palm.lock.yaml` | yes | new commits, resolved tags, hashes, trust |
| harness files and `.palm/assets/` | yes | the changed entries |
| `~/.palm/cache/` | yes | new checkouts and indexes, also under `--dry-run` |

## Exit codes

| Code | When |
| --- | --- |
| `0` | The plan was applied, declined, or printed with `--dry-run`. |
| `1` | A source failed, an entry failed, a program needs consent without a terminal, the plan needs `--yes` without a terminal, or `--dry-run --strict` found a source behind its ref. |
| `2` | An unknown option or source argument. |
| `130` | You pressed Esc or Ctrl-C at a prompt. |
