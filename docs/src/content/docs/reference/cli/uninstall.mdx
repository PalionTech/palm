`palm uninstall` deletes the files palm wrote for an entity, reverses its merged config and updates `palm.yaml` and `palm.lock.yaml`.

```sh
palm uninstall [kind] <name[@origin]>... [options]
palm uninstall origin <alias>... [options]
```

Aliases: `palm remove`, `palm rm`, `palm delete`.
Kinds: `skill`, `agent`, `instruction`, `command`, `hook`, `mcp`, `plugin` and `origin`, as singular, plural or [short name](/palm/reference/cli/#kinds).
Without a kind, palm matches the name in every entity kind.

| Command | Meaning |
| --- | --- |
| `palm uninstall skill tdd` | Remove a skill and the dependencies nothing else needs. |
| `palm uninstall skills tdd grill-me` | Remove several skills. |
| `palm rm plugin superpowers -g` | Remove a plugin and its members from the global scope. |
| `palm uninstall mcp docs --dry-run` | Show what palm would remove. |
| `palm uninstall skill tdd --force` | Also delete files you changed since palm wrote them. |
| `palm uninstall origin pstack` | Unregister an origin. Installed entities stay. |

## Options

{/* cli-reference:options uninstall */}

| Argument | Meaning |
| --- | --- |
| `kind` | skill, agent, instruction, command, hook, mcp, plugin, origin (plurals and short names work); omit it to match every entity kind |
| `names` | `name[@origin][#ref]` |

No options of its own. The [global options](/palm/reference/cli/#global-options) apply.

{/* /cli-reference */}

## Dependencies

An entity that an agent or plugin pulled in goes with it, unless something still needs it:

- `palm.yaml` lists it directly. It stays and becomes a direct install.
- Another installed plugin or agent declares it. It stays, and the lockfile records that entry as its parent.

`palm why <kind> <name>` shows what keeps an entity installed.

## Behavior

### What it writes

- Deletes every file the lockfile lists for the entity, and removes the directories palm emptied. It never removes a harness folder such as `.claude`, `.github` or `.cursor`.
- Removes exactly the values palm merged into shared files, such as `.mcp.json` or `.claude/settings.json`. It prunes containers palm emptied and deletes a JSON file left as `{}`.
- Removes palm's own managed blocks from `AGENTS.md` and `GEMINI.md`.
- Removes the entry from `palm.yaml`, and the section when it becomes empty, then updates `palm.lock.yaml`.
- `palm uninstall origin` removes the alias from `~/.palm/config.yaml` and from the project's `palm.yaml`.

### What it asks

Nothing.

### What it refuses

- A file you changed since palm wrote it stays on disk and is listed. Repeat the command with `--force` to delete it.
- A name installed as two kinds: `E_AMBIGUOUS`. Name the kind.
- A name that is not installed in the scope: `E_NOT_FOUND`. Add `-g` for the global scope.

When a target cannot remove its files, palm prints an `x` line.
The entry stays in the lockfile with what is still on disk.

## Exit codes

| Code | When |
| --- | --- |
| `0` | Every named entity is removed. Files you changed and kept do not change the code. |
| `1` | A name or alias is not found, a name is ambiguous, or a file could not be removed. |
| `2` | A usage error, such as no name. |
