`palm audit` scans every file palm installed for hidden Unicode, and reports files that changed since palm wrote them.

```sh
palm audit [kind] [names...] [options]
```

Kinds: `skill`, `agent`, `instruction`, `command`, `hook`, `mcp` and `plugin`, as singular, plural or [short name](/palm/reference/cli/#kinds).
Without a kind, palm scans every kind.

| Command | Meaning |
| --- | --- |
| `palm audit` | Scan everything palm installed, in the project and the global scope. |
| `palm audit skills tdd` | One skill. |
| `palm audit --strip` | Remove the hidden characters from the files. |
| `palm audit --strip --dry-run` | Show what `--strip` would remove. |
| `palm audit -g --json` | The global scope only, as JSON. |

## Options

{/* cli-reference:options audit */}

| Argument | Meaning |
| --- | --- |
| `kind` | skill, agent, instruction, command, hook, mcp, plugin (plurals and short names work); omit it for every kind |
| `names` | only these entities |

| Option | Meaning |
| --- | --- |
| `--strip` | remove the hidden characters from the files |

The [global options](/palm/reference/cli/#global-options) also apply.

{/* /cli-reference */}

## Findings

| Severity | Characters |
| --- | --- |
| critical | Bidirectional overrides and isolates: U+202A to U+202E, U+2066 to U+2069; tag characters: U+E0000 to U+E007F; variation selectors 17 to 256: U+E0100 to U+E01EF |
| warning | Zero-width and other invisible format characters; for example U+200B to U+200F, U+2060 to U+2064 and U+00AD; U+FEFF after the first character |

A zero-width joiner inside an emoji sequence is not a finding.
For each file, palm prints the count per severity and the first code point with its line and column.
It also reports drift: a file that is missing, or whose hash differs from the lockfile's.

## Behavior

### What it writes

Nothing, unless `--strip`.
`--strip` removes every finding from the scanned files and keeps a leading byte order mark.
It writes each file atomically and records the new hash in the lockfile when the file matched it before.

### What it asks

Nothing.

### What it refuses

It never reads a lockfile path that points outside its scope.

Without `-g`, palm scans the project and the global scope.
With `-g`, or when the project would be your home directory, it scans only the global one.
With `--json`, the document is `{ "scanned", "files", "remaining": { "critical", "warning" }, "drifted" }`.

## Exit codes

| Code | When |
| --- | --- |
| `0` | No critical finding remains. Warnings and drift do not change the code. |
| `1` | A critical finding remains, or a name you gave is not installed (`E_NOT_FOUND`). |
| `2` | A usage error. |
