Every palm command is a verb followed by its arguments. For `install` and `remove`, the source comes first.

```sh
palm <verb> [source] [[kind:]name...] [options]
```

| Command | Meaning |
| --- | --- |
| `palm install mattpocock/skills` | List what a source offers. Writes nothing. |
| `palm install mattpocock/skills tdd grill-me` | Install two entities from one source and declare the source in `palm.yaml`. |
| `palm install anthropics/claude-plugins-official mcp:context7` | Name the kind when one name means two kinds in that source. |
| `palm install` | Make the disk match `palm.yaml` and the lock. |
| `palm remove tdd` | Remove an entity by name. |
| `palm get skills` | List installed skills. |
| `palm describe .mcp.json` | Show which entities wrote a file. |
| `palm install mattpocock/skills handoff -g` | The same verbs in your home directory. |

## Verbs

{/* cli-reference:verbs */}

| Verb | Aliases | Meaning |
| --- | --- | --- |
| [`init`](/palm/reference/cli/init/) |  | write palm.yaml with the targets for this project |
| [`install`](/palm/reference/cli/install/) | `add`, `i` | list a source, install from it, or sync the disk with palm.yaml |
| [`remove`](/palm/reference/cli/remove/) | `uninstall`, `rm` | delete exactly what an entity wrote |
| [`update`](/palm/reference/cli/update/) | `up` | move sources to the newest commit their ref allows |
| [`check`](/palm/reference/cli/check/) |  | read-only gate: palm.yaml, lock, files and sources agree |
| [`get`](/palm/reference/cli/get/) | `list`, `ls` | list installed entities, sources or targets |
| [`describe`](/palm/reference/cli/describe/) | `info` | show one entity, source, target or file owner |
| [`create`](/palm/reference/cli/create/) | `new` | write a template into the in-repo source and install it |

`palm help <command>` prints the same text as `palm <command> --help`.
`--help` fits on one screen and lists no exit codes. This site lists them.

## Kinds

`install` and `remove` take a kind as a prefix, `kind:name`, only when one name means two kinds in a source.
`get` and `describe` take a kind as a word, singular, plural or short.

{/* cli-reference:kinds */}

| Kind | Short name | Other words | Verbs |
| --- | --- | --- | --- |
| `skill` | `sk` | `skills` | `get`, `describe` |
| `agent` | `ag` | `agents` | `get`, `describe` |
| `instruction` | `ins` | `instructions` | `get`, `describe` |
| `hook` | `hk` | `hooks` | `get`, `describe` |
| `mcp` |  |  | `get`, `describe` |
| `plugin` | `pl` | `plugins` | `get`, `describe` |
| `source` | `src` | `sources` | `get`, `describe` |
| `target` | `tg` | `targets` | `get`, `describe` |
| `all` |  |  | `get` |

{/* /cli-reference */}

`cmd`, `command` and `commands` mean `skill`, with a note, because commands install as skills.
`origin` and `orig` mean `source` for one release.

## Global options

Every command accepts these options.

{/* cli-reference:global-options */}

| Option | Meaning |
| --- | --- |
| `-g, --global` | use the global scope (~/.palm/palm.yaml and the harness homes) |
| `--dry-run` | show what would change; write nothing |
| `--force` | replace files palm does not own or you changed |
| `-y, --yes` | accept defaults for prompts that are not consent |
| `--allow-exec <list>` | consent to programs by key and hash: kind:name@source=sha256:hash, comma-separated |
| `--offline` | use the cache only; no network |
| `--json` | one JSON document on stdout; everything else on stderr |
| `--secrets <policy>` | env-ref (default) or literal |
| `--local` | reserved for palm.local.yaml (palm 0.3) |
| `-V, --version` | print the palm version |
| `-h, --help` | display help for command |

{/* /cli-reference */}

### What the options do

| Option | Detail |
| --- | --- |
| `-g` | Works with every verb. The global scope has its own `~/.palm/palm.yaml`, lock and sources. See [scopes](/palm/concepts/scopes/). |
| `--dry-run` | Resolves and renders everything, prints `would install` and `would restore` lines, and writes nothing in the scope. palm may still fetch into its cache. |
| `--force` | Replaces a file palm did not write or you changed since palm wrote it. Never overrides hidden Unicode, an unresolvable hook reference, or a literal secret from a source. |
| `--yes` | Accepts pickers and plan confirmations, such as `Apply 2 changes?`. It never consents to a program. |
| `--allow-exec` | Consents to programs by exact hash, as printed by the consent error. `all` works only on a terminal. See [consent](/palm/concepts/consent/). |
| `--offline` | Reads sources from the cache only. A commit that is not cached fails with `E_NETWORK`. |
| `--json` | See [JSON output](#json-output). |
| `--secrets literal` | Writes typed secret values instead of references. See [secrets](/palm/concepts/secrets/). |
| `--local` | Stops with a usage error in 0.2: `palm.local.yaml` arrives in 0.3. |

There is no `--verbose` and no `--no-color`. Set `PALM_DEBUG=1` for debug lines and `NO_COLOR=1` to turn colour off.

## Prompts

palm prompts only on a terminal, and every prompt has a flag.

| Prompt | Default | Without a terminal |
| --- | --- | --- |
| Allow these programs to run? | no | `E_UNTRUSTED_EXEC`, naming the `--allow-exec` line |
| Apply the update plan | no | `E_NON_INTERACTIVE`, naming `--yes` |
| Change a declared source's ref | no | `E_NON_INTERACTIVE`, naming `--yes` |
| Clean the cache | no | `E_NON_INTERACTIVE`, naming `--yes` |
| A secret value under `--secrets literal` | none | `E_NON_INTERACTIVE`, naming `--secrets env-ref` |

palm never asks which targets or which source to use. Those come from `palm.yaml` and the command line.

## Output

Data goes to stdout. Each status line starts with a symbol.

| Symbol | Meaning |
| --- | --- |
| `+` | installed or added |
| `-` | removed |
| `~` | updated or re-rendered |
| `↺` | restored: a missing generated file written again |
| `=` | unchanged: the render equals the lock and the disk equals the render, on every target |
| `⊘` | skipped for one target, with the reason |
| `x` | error or failed |
| `!` | warning, a modified file palm kept, or a partial install |
| `i` | information |

Warnings are collected and printed once at the end, on stderr, under a `Warnings` heading.
An error comes last, as an `x` line with the message and then a hint that is a command you can paste.
When the same command with another flag fixes the error, the hint repeats your command with that flag.

Colour appears only when stdout is a terminal. `NO_COLOR=1` turns it off.

### JSON output

With `--json`, stdout holds exactly one JSON document and every other line goes to stderr.
A list comes as `{ "items": [...] }`, and every document has a `warnings` array.
An error is `{ "error": { "code", "message", "hint" }, "warnings": [] }`, and the exit code still reports it.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success, including `--help`, `--version` and a bare `palm`. Warnings never change it. |
| `1` | Failure: a refusal, a failed or partial install, a modified file palm kept, or a failed check |
| `2` | Usage error: an unknown command, option or argument, a removed 0.1 command, or a 0.1 `palm.yaml` |
| `130` | Cancelled: Esc or Ctrl-C at a prompt, or a declined plan |

[Exit codes and errors](/palm/reference/exit-codes/) lists every error code with its fix.

## Old commands

The palm 0.1 grammar works for one release as hidden aliases.

<Capture name="c-legacy" title="~/project" />

The 0.1 form `install skill tdd@mattpocock` resolves the alias `mattpocock` through `palm.yaml` and runs.
The removed commands `doctor`, `audit`, `outdated`, `why`, `find`, `search` and `config` print one line naming the replacement and exit 2.
[Migrate from palm 0.1](/palm/guides/migrate-from-0-1/#old-commands) maps each one.
