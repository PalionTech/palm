palm exits with one of five codes, and every error carries a stable code such as `E_NOT_FOUND`.

```sh
palm install --frozen --json || echo "palm failed with $?"
```

| Code | Meaning |
| --- | --- |
| `0` | Success, including `--help`, `--version` and a bare `palm`. Warnings never change it. |
| `1` | Failure: an error other than a usage error or a cancel, or a command that reports a failed item. |
| `2` | Usage error: an unknown command, option or argument, or a kind the verb does not take. |
| `70` | Internal error: an unexpected exception. `--verbose` prints the stack trace. |
| `130` | Cancelled: a declined confirmation, Esc at a prompt, or Ctrl-C. palm prints nothing more. |

## Reports that exit 1

Some commands finish their report and then exit 1 without an error line:

| Command | Exits 1 when |
| --- | --- |
| `palm install` | Any entity, target or origin failed. The lockfile records what succeeded. |
| `palm uninstall` | A file or target could not be removed. |
| `palm update` | An origin, the registry or a deploy failed. |
| `palm update origins` | One origin could not be fetched or scanned. |
| `palm audit` | A critical hidden Unicode finding remains. |
| `palm doctor` | A check failed. |
| `palm find` | No entity wrote the path. |

`palm outdated` is informational and always exits 0.

## Error codes

| Code | Exit | Cause | Fix |
| --- | --- | --- | --- |
| `E_USAGE` | 2 | An unknown command, option, kind or target; a missing name; options that do not go together; project scope in your home directory. | Follow the hint, or read `palm <verb> --help`. |
| `E_NOT_FOUND` | 1 | No origin has the name; no origin has the alias; the entity is not installed in the scope; no entity wrote the path. | Search with `palm search`, add an origin with `palm install origin`, or add `-g`. |
| `E_AMBIGUOUS` | 1 | Several origins have the name and there is no terminal; a name is installed as two kinds; `-o` matches several origins. | Write `name@origin`, add the kind word, or pass the alias. |
| `E_CONFLICT` | 1 | A file palm did not write is in the way; you changed a file palm wrote; a shared file holds another value at palm's key; an entity has critical hidden Unicode; `--frozen` found a difference; an alias is taken. | Review the file, then pass `--force`; run `palm audit`; run `palm install` without `--frozen` and commit; pick another `--alias`. |
| `E_ORIGIN` | 1 | palm refuses the origin spec or URL; a local path is missing; no tag matches the ref or range; the origin could not be fetched and indexed. | Check the spec. `git ls-remote --tags <url>` lists the refs. |
| `E_GIT` | 1 | git is not on `PATH`, a clone or fetch failed, or a local git step hung for 30 seconds. | Install git, set up credentials for private repositories, or run `palm cache clean`. |
| `E_NETWORK` | 1 | A remote did not answer within 120 seconds; an origin is not cached under `--offline`; the MCP registry or a marketplace URL failed. | Check the network, VPN or proxy. Run once without `--offline`. |
| `E_PARSE` | 1 | `palm.yaml`, `palm.lock.yaml`, `config.yaml` or a marketplace file is invalid; an origin has no alias, or a duplicate one; the lockfile version is unknown. | Fix the named file, restore it from version control, or upgrade palm. |
| `E_TARGET` | 1 | No harness is detected and there is no terminal to ask, or you selected no target. | Pass `--target`, run `palm init`, or run `palm config set targets`. |
| `E_IO` | 1 | palm cannot read, write or hash a file, or another palm process holds an origin's checkout lock. | Check permissions. Wait for the other process, or delete the lock file the message names. |
| `E_NON_INTERACTIVE` | 1 | palm needs an answer and has no terminal: consent to run commands, an update or cache confirmation, a secret value, or the `palm create` wizard. | Pass `--yes`, export the variable, or run in a terminal. |
| `E_CANCELLED` | 130 | You declined, pressed Esc, or pressed Ctrl-C. During an install, palm finishes the current entity and saves the lockfile first. | Run the command again. |
| `E_INTERNAL` | 70 | An unexpected exception: a bug in palm. A few internal checks report this code with exit 1. | Run again with `--verbose` and [report it](/palm/reference/troubleshooting/#report-a-bug). |

## JSON errors

With `--json`, an error is the only document on stdout: `{ "error": { "code", "message", "hint" }, "warnings": [] }`.

<Capture name="c-json" />

`hint` is left out when there is none, as for usage errors from the argument parser.
An install that partly fails is not an error document: its result lists each failure in `failures`, with `kind`, `name`, `origin`, `target`, `code`, `message` and `hint`, and palm exits 1.
