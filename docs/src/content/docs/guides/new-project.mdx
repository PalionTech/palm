A new repository needs the same skills, agents and MCP servers in Claude Code and in Codex.
Copying them by hand means two folders, two config files and no record of where anything came from.
With palm it takes four commands, and a lockfile records every file for the next developer.

When you finish, the project holds these files:

<CaptureTree name="b-new-project" depth={3} />

`palm.yaml` lists what you asked for, and `palm.lock.yaml` records each file palm wrote.
The sessions on this page ran against palm's test fixtures, which mirror `mattpocock/skills` and `anthropics/claude-plugins-official`.

## Before you start

- palm, git and Node 22 or later. See [Installation](/palm/getting-started/install/).
- A git repository with a `.gitignore` file.

## Steps

<Steps>

1. Add the two origins. An **origin** is a repository palm installs from.

   ```sh
   palm install origin mattpocock/skills
   palm install origin anthropics/claude-plugins-official --alias official
   ```

   palm clones each repository, scans it and saves it in `~/.palm/config.yaml`.

2. Choose the harnesses for this project.

   ```sh
   palm init --target claude,codex
   ```

   palm writes `targets: [claude, codex]` to `palm.yaml` and adds `.palm/` to `.gitignore`.
   It edits only an existing `.gitignore`, so create the file first if the project has none.
   `.palm/` holds the hook scripts palm copies, and those stay out of git.

3. Install a skill.

   ```sh
   palm install skill tdd@mattpocock
   ```

   `@mattpocock` names the origin. You can leave it out when only one origin has a skill called `tdd`.

4. Install an agent (subagent) together with its dependencies.

   ```sh
   palm install agent agent-sdk-verifier-py
   ```

   An agent file can name the skills and MCP servers it uses, and palm installs them with it.
   In the fixture, the agent names the skill `sdk-helper` and the MCP server `context7`.

5. Add an MCP server of your own.

   ```sh
   palm install mcp docs --url https://docs.example.com/mcp
   ```

   The server declares no token, so each harness starts OAuth the first time it connects.

6. Commit the manifest, the lockfile and the files palm wrote.

   ```sh
   git add -A
   git commit -m "Set up coding agents with palm"
   ```

</Steps>
