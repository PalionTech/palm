Many projects began by copying an agent (subagent) or a skill from GitHub into `.claude/` or `.cursor/`.
Those copies drift from their source, and nobody remembers where they came from.
palm takes them over: you name each source once, and the lockfile tracks the file from then on.

When you finish, palm names the entity behind each file and lists everything it now tracks:

<Capture name="b-adopt-result" title="~/project" />

The sessions on this page ran against palm's test fixtures, which mirror `mattpocock/skills` and `cursor/plugins`.

## Before you start

- Commit your current files, so `git diff` shows what palm changes.
- Know or find the repository each copy came from.

## Steps

<Steps>

1. Take stock of the harness folders.

   ```sh
   find .claude .cursor .github .agents -type f
   ```

   | Folder | Holds files for |
   | --- | --- |
   | `.claude/agents`, `.claude/skills`, `.claude/rules`, `.claude/commands` | Claude Code |
   | `.cursor/agents`, `.cursor/rules`, `.cursor/commands` | Cursor |
   | `.github/agents`, `.github/instructions`, `.github/prompts` | GitHub Copilot |
   | `.codex/agents`, `.gemini/agents`, `.opencode/agents` | Codex, Gemini CLI and OpenCode |
   | `.agents/skills` | every harness except Claude Code |
   | `.mcp.json`, `.vscode/mcp.json`, `.cursor/mcp.json` | MCP servers |

2. Add the origin each copy came from, and find the entity in it.

   ```sh
   palm install origin cursor/plugins/pstack --alias pstack
   palm search comment-sicko
   ```

3. Install the entity over your copy.

   ```sh
   palm install agent comment-sicko
   ```

   palm never overwrites a file it did not write, so the first attempt fails and names each file.
   Your copy differs from what palm writes: palm normalises the agent's `name` to its file name.

4. Repeat with `--force` once you have checked the file.

   ```sh
   palm install agent comment-sicko --force
   git diff
   ```

   `--force` replaces your copy and records it in `palm.lock.yaml`.
   `git diff` shows exactly what changed.

5. Adopt the remaining copies the same way.

   ```sh
   palm install skill tdd@mattpocock
   ```

   A copy that is byte for byte what palm would write needs no `--force`: palm records it and moves on.
   This is the full session for steps 3 to 5:

   <Capture name="b-adopt" title="~/project" />

   The first install also saved the detected targets, `claude` and `cursor`, to `palm.yaml`.

</Steps>

:::caution
`--force` overwrites every file the entity writes, local edits included.
Commit first, so you can bring an edit back with git.
:::

MCP servers work the same way.
A server you wrote into `.mcp.json` by hand blocks `palm install mcp <name>` for that harness until you pass `--force`.

## Check the result

Ask palm which entity wrote a file:

```sh
palm find .claude/agents/comment-sicko.md
```

palm prints the scope, kind, name, origin and target that own the file.
For a file no entity wrote, it exits 1. That file stays yours, and palm never deletes it.
