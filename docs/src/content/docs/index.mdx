The agent became a Markdown file for Claude Code, Cursor, Gemini CLI and OpenCode, a TOML file for Codex and an `.agent.md` file for Copilot.
The skill went to `.claude/skills` for Claude Code, which Cursor reads too, and once to `.agents/skills` for the other four.
`palm.yaml` names the two sources and what you took from them. `palm.lock.yaml` pins each source to a commit and lists every file palm wrote.
Commit all of it, and a teammate's clone works with no palm run at all.

## How it works

<CardGrid>
  <Card title="Any repository, as it is" icon="open-book">
    palm reads Claude Code, Cursor and Codex plugins, marketplaces, APM packages and plain
    `SKILL.md` folders. Authors repackage nothing, and `owner/repo` is the whole address.
  </Card>
  <Card title="Native files per harness" icon="document">
    An agent becomes `.md`, `.toml` or `.agent.md`. Hooks and MCP servers merge into each tool's
    own config file, and `palm remove` takes out exactly those entries.
  </Card>
  <Card title="Sources live in the project" icon="list-format">
    `palm.yaml` declares every source with its version range. A clone carries everything palm
    needs, with no per-user setup and no alias to register first.
  </Card>
  <Card title="Committed, then checked" icon="approve-check">
    You commit the generated files, so git is the review and the record. In CI, `palm check`
    recomputes every file from the lock and fails on any difference.
  </Card>
  <Card title="Programs need a yes" icon="warning">
    Before a hook or a stdio MCP server lands, palm shows each command and script. The default is
    no, and your yes is pinned by hash in the lock, so any change asks again.
  </Card>
  <Card title="Secrets stay out of git" icon="padlock">
    Project files get each harness's environment reference, such as `${env:TOKEN}` for Cursor. A
    literal secret that arrives from a source is never written.
  </Card>
</CardGrid>

## Where files go

Project scope, for the six targets.
The [targets matrix](/palm/reference/targets-matrix/) adds global paths and the combinations a harness does not support.

<div class="palm-wide palm-paths">

| Harness | skill | agent | instruction | hook | mcp |
| --- | --- | --- | --- | --- | --- |
| Claude Code | `.claude/skills/<n>/` | `.claude/agents/<n>.md` | `.claude/rules/<n>.md` | `.claude/settings.json` | `.mcp.json` |
| Codex | `.agents/skills/<n>/` | `.codex/agents/<n>.toml` | block in `AGENTS.md` | `.codex/hooks.json` | `.codex/config.toml` |
| GitHub Copilot | `.agents/skills/<n>/` | `.github/agents/`<br />`<n>.agent.md` | `.github/instructions/`<br />`<n>.instructions.md` | `.github/hooks/<n>.json` | `.vscode/mcp.json` |
| Cursor | `.claude/skills/<n>/` with `claude`, else `.agents/skills/<n>/` | `.cursor/agents/<n>.md` | `.cursor/rules/<n>.mdc` | `.cursor/hooks.json` | `.cursor/mcp.json` |
| Gemini CLI | `.agents/skills/<n>/` | `.gemini/agents/<n>.md` | block in `GEMINI.md` | `.gemini/settings.json` | `.gemini/settings.json` |
| OpenCode | `.agents/skills/<n>/` | `.opencode/agents/`<br />`<n>.md` | `.opencode/instructions/`<br />`<n>.md` | not supported | `opencode.json` |

</div>

Scripts that hooks run go to `.palm/assets/<source>/`, and you commit them with everything else.
