The agent became a Markdown file for Claude Code, Cursor, Gemini CLI and OpenCode.
Codex got a TOML file, and Copilot got an `.agent.md` file.
The skill went to `.claude/skills` for Claude Code and once to `.agents/skills`, which the other five read.
`palm.yaml` lists what you asked for, and `palm.lock.yaml` records every file palm wrote.

## One name in two origins

<Capture name="a-ambiguity" title="~/project" />

Two origins offer a skill named `tdd`, and `palm search` shows both.
In a terminal, `palm install skill tdd` opens a picker.
In a script, it exits with `E_AMBIGUOUS` and prints `tdd@mattpocock` and `tdd@pstack`.
The `@origin` suffix picks one, and palm records that choice in `palm.yaml`.

## How it works

<CardGrid>
  <Card title="Any repository, as it is" icon="open-book">
    palm reads Claude Code and Cursor plugins, marketplaces, APM packages and plain `SKILL.md`
    folders. It detects the layout, so authors repackage nothing.
  </Card>
  <Card title="Native files per harness" icon="document">
    An agent becomes `.md`, `.toml` or `.agent.md`. Hooks and MCP servers merge into each tool's
    own config file, and uninstall removes exactly those entries.
  </Card>
  <Card title="One name across your origins" icon="magnifier">
    `palm install skill tdd` searches every origin you added. When two match, palm asks, or
    names the `tdd@origin` forms in a script.
  </Card>
  <Card title="Agents bring their tools" icon="puzzle">
    An agent names the skills and MCP servers it uses. palm installs them with the agent and
    removes them once nothing else needs them.
  </Card>
  <Card title="Secrets stay out of git" icon="padlock">
    Project files get each harness's environment reference, such as `${env:TOKEN}` for Cursor. The
    lockfile stores the placeholder, never the value.
  </Card>
  <Card title="Reproducible for the whole team" icon="approve-check">
    The lockfile pins each commit and hashes every file. `palm install --frozen` fails in CI on any
    difference. Hooks and stdio MCP servers install only after you confirm them.
  </Card>
</CardGrid>

## Where files go

Project scope, for the six targets.
The [targets matrix](/palm/reference/targets-matrix/) adds commands, global paths and the combinations a harness does not support.

<div class="palm-wide">

| Kind | Claude Code | Codex | GitHub Copilot | Cursor | Gemini CLI | OpenCode |
| --- | --- | --- | --- | --- | --- | --- |
| skill | `.claude/skills/<n>/` | `.agents/skills/<n>/` | `.agents/skills/<n>/` | `.agents/skills/<n>/` | `.agents/skills/<n>/` | `.agents/skills/<n>/` |
| agent | `.claude/agents/<n>.md` | `.codex/agents/<n>.toml` | `.github/agents/<n>.agent.md` | `.cursor/agents/<n>.md` | `.gemini/agents/<n>.md` | `.opencode/agents/<n>.md` |
| instruction | `.claude/rules/<n>.md` | block in `AGENTS.md` | `.github/instructions/<n>.instructions.md` | `.cursor/rules/<n>.mdc` | block in `GEMINI.md` | `.opencode/instructions/<n>.md` |
| hook | `.claude/settings.json` | `.codex/hooks.json` | `.github/hooks/<n>.json` | `.cursor/hooks.json` | `.gemini/settings.json` | not supported |
| mcp | `.mcp.json` | `.codex/config.toml` | `.vscode/mcp.json` | `.cursor/mcp.json` | `.gemini/settings.json` | `opencode.json` |

</div>
