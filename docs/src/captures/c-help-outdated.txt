$ palm outdated --help
Usage: palm outdated [options] [kind]

Show, for each direct install, the locked ref, the ref palm.yaml wants now and
the latest release.

Arguments:
  kind                skill, agent, instruction, command, hook, mcp, plugin
                      (plurals and short names work); omit it for every kind

Options:
  -h, --help          display help for command

Global Options:
  -g, --global        use the global scope (~), not this project
  -t, --target <ids>  targets: claude,codex,copilot,cursor
  --dry-run           show what would change; write nothing
  --force             overwrite files palm does not own
  -y, --yes           accept defaults instead of prompting
  --offline           use cached origins only; no network
  --verbose           debug output and stack traces
  --json              JSON on stdout; everything else on stderr
  --no-color          no colours (also NO_COLOR=1)
  -V, --version       print the palm version

Columns:
  current    the ref palm.lock.yaml records
  wanted     what palm.yaml's #ref resolves to now: a tag, a branch head, or the newest tag
             in a semver range (#^1.2, #~1.2); no #ref: the latest release
  latest     the newest release tag, else the default branch head
Reads remote refs only (git ls-remote); the cache is never taken as current.

Examples:
  palm outdated                             every direct install in this project
  palm outdated skills                      skills only
  palm outdated -g --json                   global installs, as JSON
