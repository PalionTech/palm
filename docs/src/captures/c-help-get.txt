$ palm get --help
Usage: palm get|list [kind] [names...] [options]

List what is installed, the sources or the targets.

Arguments:
  kind                   skill, agent, instruction, hook, mcp, plugin; source,
                         target or all
  names                  only these names

Options:
  -s, --source <source>  only what came from this source
  --files                every file palm wrote, with its entry
  -h, --help             display help for command

Global Options:
  -g, --global           use ~/.palm/palm.yaml and the harness home directories
  --dry-run              show what would change; write nothing
  --force                replace files you changed or that palm does not own
  -y, --yes              accept plan confirmations (never consents to programs)
  --allow-exec <list>    allow programs: hook:x@source=sha256:hash,... or all
  --offline              use the cache only; no network
  --json                 one JSON document on stdout; everything else on stderr
  --secrets <policy>     env-ref (default) or literal, for secrets you type
  -V, --version          print the palm version

Kinds: skill (sk), agent (ag), instruction (ins), hook (hk), mcp, plugin (pl); also
source (src), target (tg) and all. Plurals work too.

Examples:
  palm get
  palm get skills
  palm get --source mattpocock/skills --files
  palm get sources
  palm get targets -g
