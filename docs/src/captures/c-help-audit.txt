$ palm audit --help
Usage: palm audit [options] [kind] [names...]

Scan the files palm installed for hidden Unicode (bidi overrides, tag
characters, zero-width characters) and for changes since install.

Arguments:
  kind                skill, agent, instruction, command, hook, mcp, plugin
                      (plurals and short names work); omit it for every kind
  names               only these entities

Options:
  --strip             remove the hidden characters from the files
  -h, --help          display help for command

Global Options:
  -g, --global        use the global scope (~), not this project
  -t, --target <ids>  comma-separated: claude, codex, copilot, cursor, gemini,
                      opencode
  --dry-run           show what would change; write nothing
  --force             overwrite files palm does not own
  -y, --yes           accept defaults instead of prompting
  --offline           use cached origins only; no network
  --verbose           debug output and stack traces
  --json              JSON on stdout; everything else on stderr
  --no-color          no colours (also NO_COLOR=1)
  -V, --version       print the palm version

Without -g the project and the global scope are scanned. Exit 1 while a critical finding
(bidi override, tag character) remains.

Examples:
  palm audit                                scan what palm installed for hidden Unicode
  palm audit skills tdd                     one skill
  palm audit --strip                        remove the hidden characters it finds
  palm audit -g --json                      the global scope only, as JSON
