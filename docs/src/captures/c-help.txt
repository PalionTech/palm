$ palm --help
Usage: palm <verb> [kind] [names...] [options]

Package manager for agent resources: skills, agents, instructions, commands,
hooks, MCP servers and plugins.

Verbs:
  install (add, i)                install entities or register an origin
  uninstall (remove, rm, delete)  remove entities or unregister an origin
  get (list, ls)                  list installed entities, origins, targets
  describe (info)                 show one entity, origin or target
  update (up)                     update entities or refresh origin indexes
  create (new)                    create a skill, agent, instruction or command
  search                          search origins and the MCP registry

Utilities:
  init                            create palm.yaml for this project
  doctor                          check git, node, harnesses, drift, origins
  outdated [kind]                 show current, wanted and latest refs
  why <kind> <name>               show why an entity is installed
  find <path>                     show which entity wrote a file
  audit [kind] [names...]         scan installed files for hidden Unicode
  config                          read or change global settings
  completion <shell>              print a shell completion script
  cache                           show or clear the origin cache
  help [command]                  show help for a verb or utility

Options:
  -g, --global                    use the global scope (~), not this project
  -t, --target <ids>              comma-separated: claude, codex, copilot,
                                  cursor, gemini, opencode
  --dry-run                       show what would change; write nothing
  --force                         overwrite files palm does not own
  -y, --yes                       accept defaults instead of prompting
  --offline                       use cached origins only; no network
  --verbose                       debug output and stack traces
  --json                          JSON on stdout; everything else on stderr
  --no-color                      no colours (also NO_COLOR=1)
  -V, --version                   print the palm version
  -h, --help                      display help for command

Kinds: skill (sk), agent (ag), instruction (ins), command (cmd), hook (hk), mcp, plugin (pl),
       origin (orig), target (tg), all. Plurals work too: palm get skills.

Examples:
  palm install origin mattpocock/skills
  palm get skills --available
  palm install skill tdd@mattpocock
  palm describe skill tdd
  palm uninstall skill tdd

Run palm <verb> --help for the forms each verb accepts.
Exit codes: 0 ok, 1 failure, 2 usage error, 130 cancelled, 70 internal error.
