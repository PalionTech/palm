$ palm update --help
Usage: palm update|up [options] [kind] [names...]

Update entities or refresh origin indexes.

Arguments:
  kind                skill, agent, instruction, command, hook, mcp, plugin,
                      origin (plurals and short names work); omit it for
                      everything installed
  names               name[@origin][#ref]

Options:
  -h, --help          display help for command

Global Options:
  -g, --global        use the global scope (~), not this project
  -t, --target <ids>  targets: claude,codex,copilot,cursor
  --dry-run           show what would change; write nothing
  --force             overwrite files palm does not own
  -y, --yes           accept defaults instead of prompting
  --offline           use cached origins only; no network
  --verbose           debug output and stack traces
  --json              JSON on stdout; everything else on stderr
  --no-color          no colours (also NO_COLOR=1)
  -V, --version       print the palm version

Prints the plan first (~ updated, + added, - removed, = unchanged, x failed, and files you
changed that an update would overwrite), then asks before applying (default No). Without a
terminal, --yes is required.

Examples:
  palm update                               everything installed in this project
  palm update skills                        every directly installed skill
  palm update skill tdd --dry-run           show the plan only
  palm update --yes                         apply without asking (scripts, CI)
  palm update origins                       refetch and rescan every origin
  palm update origin mattpocock             one origin
