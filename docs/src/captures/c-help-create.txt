$ palm create --help
Usage: palm create|new [options] [kind] [names...]

Create a skill, agent, instruction or command.

Arguments:
  kind                skill, agent, instruction, command (plurals and short
                      names work)
  names               name[@origin][#ref]

Options:
  --no-install        only write the file; do not install it
  -h, --help          display help for command

Global Options:
  -g, --global        use the global scope (~), not this project
  -t, --target <ids>  targets: claude,codex,copilot,cursor
  --dry-run           show what would change; write nothing
  --force             overwrite files palm does not own
  -y, --yes           accept defaults instead of prompting
  --offline           use cached origins only; no network
  --verbose           debug output and stack traces
  --json              JSON on stdout; everything else on stderr
  --no-color          no colours (also NO_COLOR=1)
  -V, --version       print the palm version

Examples:
  palm create skill release-notes
  palm create agent code-reviewer -g
  palm create instruction ts-style --no-install
  palm new command changelog
